I want to make a top-down 2d game. The core is somewhat straightforward:

- A world with forests and plains
- Deer to hunt
- Sticks fall from trees occasionally
- Human NPCs & real players
    - can take sticks and sharpen them into pointed spears
    - sneak up on deer and stab them to kill them
    - take sticks and make fire
    - cook meat on the fire
    - eat the meat

The terrain is tile based, with a treat occupying a tile.

In the future, people will build houses and such. But this core is sufficient for now

Crucial rules:
- The world is procedurally generated from a seed
- Absent human input, the game must be entirely deterministic: re-running the game with 0 human input with the same seed must yield an identical simulation
- The NPCs must be black-boxed, so I can try lots of completely different NPC code
- The game should be entirely in JavaScript & Canvas. A minimum python server can serve the files.
- The human player should have a button to speed up time in the game, while maintaining determinism.
- You must be able to run automated tests that run a full game at dramatically faster speed
